# Security Policy

## Supported versions

Security fixes are released for the latest `1.x` version. The old
`github.com/happytoolin/happycontext` module path is not maintained.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/happytoolin/unolog/security/advisories/new).
Do not open a public issue for a suspected vulnerability.

Include the affected package and version, reproduction steps, impact, and any
suggested fix. Do not include secrets or private data.
